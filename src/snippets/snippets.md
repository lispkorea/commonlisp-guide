# 자투리

## 우주로

[DS1(Deep Space 1호)](https://en.wikipedia.org/wiki/Deep_Space_1) 이온 추진을 사용한 최초의 NASA 우주선. DS1 우주선이 우주속에서 교착 상태에 빠져서 고장이 남.

- 60 million miles는 (96,560,400 km) 지구에서 태양 거리의 65%쯤 되는 거리(지구에서 달 거리의 250배쯤 된다)
  - 빛의 속도(= 299,792 km/s (약 30만 km/s))로도 5분 22초(총 322초)걸림.

Repl을 연결해서 덤프를 긁어옴, 문제를 해결할 이벤트 찾아서, 다시 DS1에 쏴서 교착상태를 품

- [youtube: The Remote Agent Experiment: Debugging Code from 60 Million Miles Away](https://www.youtube.com/watch?v=_gZK0tW8EhQ)
  - [ppt](https://flownet.com/ron/RAX2.pdf)
  - <https://www.reddit.com/r/lisp/comments/a7156w/lisp_and_the_remote_agent/>
  - [Lisping at JPL](https://flownet.com/gat/jpl-lisp.html) by Ron Garret
  - <https://corecursive.com/lisp-in-space-with-ron-garret/>
