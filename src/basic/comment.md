# 주석

주석은 세미콜론으로 시작합니다( ; )


| 세미콜론 갯수 | 쓰임세                    |
| ------------- | ------------------------- |
| 4개           | 파일 단위로는             |
| 3개           | 구획(section) 설명으로는  |
| 2개           | 정의(definition) 안에서는 |
| 1개           | 한개의 라인에 대해서      |

## 예

```
;;;; hello.lisp


;;; Welcome, Lisp World

(defun hello (a b)
  ;; a와 b를 더하고
  (+ a b))          ; 반환
```
